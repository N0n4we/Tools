# Tools

用于参考和自行验证的独立工具，不包含任何测试环境的连接配置或运行结果。

| 目录 | 内容 |
| --- | --- |
| `mqtt-test/` | MQTT 3.1.1 探测、心跳观察、报文解析和断连片段，附离线自检 |
| `network-test/` | 通过显式环境变量指定目标的 TCP/TLS 连通性探测 |
| `memory-test/` | C、Go、Python 内存使用实验 |
| `pagerduty/` | 使用自行提供的凭据发送测试事件 |
| `pi-durable/` | Durable Object 助手及其自检 |
| `.github/` | 可复用的工作流，以及单独加密的助手记忆归档 |

网络测试只应针对明确授权的系统；先使用本地模拟服务验证，再逐步增加负载。

TCP/TLS 探测示例（先替换为自己的授权目标）：

```sh
MQTT_HOST=broker.example.invalid MQTT_PORT=8883 bash network-test/nacl-blocking-test.sh
```

## 公开发布

- 只发布审查后的源码和示例配置；真实凭据、日志、抓包、数据库导出和运行目录留在本地。
- `.gitignore` 不会清理已经提交的内容。**本地旧历史包含环境标识，不应直接推到公开仓库，也不要直接把旧仓库改为公开。**
- 首次公开应从清理后的文件快照建立新仓库，不带 `.git/`、`.jj/` 或旧提交；使用 `jj` 管理新仓库。
- 本次发布快照放在被忽略的 `artifacts/public/`，只包含当前版本管理中的文件，不包含旧历史或本地运行资料。
- 密钥等动态值通过环境变量、未跟踪的本地配置或平台 Secrets 提供，不写进示例。
- 加密记忆归档按维护者要求保留。它不是公开的测试数据：本次未解密或审查其明文，安全性依赖口令强度和密钥保密；相关工作流仍会更新该归档。

可用 `gitleaks dir <待发布快照目录> --redact` 扫描明文凭据；扫描不能证明代码版权归属、识别所有业务标识，或审查加密文件内容。
